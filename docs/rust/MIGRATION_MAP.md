# M0: source-to-Rust migration map

Generated by `docs/rust/tools/gen_migration_map.py`; the script fails if any source file is not covered by a rule, so nothing is left unmapped. Symbols are extracted automatically; responsibility, destination and status are written by hand next to the rules in that script and reviewed with each milestone.

Status meanings: **Ported, tested** = the Rust implementation exists and is checked against TypeScript or Kotlin output; **Partly ported** = some of the file's responsibilities are in Rust; **Not yet ported** = still only in TypeScript or Kotlin; **Stays** = UI or platform adapter code that is meant to remain; **Replaced by a library** = a hand-written routine that a vetted crate replaces.
